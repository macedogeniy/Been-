## 📋 ОБЗОР ПРОЕКТА

### Что такое "Охота за ликвидностью"?

Торговая система "Охота за ликвидностью" - это **профессиональная система алгоритмической торговли**, реализующая продвинутую стратегию поиска и использования ликвидности на рынке криптовалют.

### ✨ Ключевые особенности

- **🎯 Стратегия "Охота за ликвидностью"**: Поиск BSL/SSL пулов и их использование
- **📊 Многотаймфреймовый анализ**: От D1 до M1 с синхронизацией
- **🧠 Человекоподобное мышление**: Адаптивная логика с эмоциональными факторами
- **📈 Детекция структуры**: HH/HL, LL/LH паттерны
- **🎨 Интерактивная визуализация**: Plotly графики с полной разметкой
- **🧪 Профессиональный бэк-тестинг**: Комплексная система анализа производительности
- **🖥️ Веб-дашборд**: Streamlit интерфейс для мониторинга
- **🚨 Система алертов**: Email, Telegram, Webhook уведомления
- **🌐 Реальные данные**: Интеграция с биржами (Binance, Coinbase)

## 🎯 СТРАТЕГИЯ "ОХОТА ЗА ЛИКВИДНОСТЬЮ"

### Концепция стратегии

Стратегия основана на понимании того, как маркет-мейкеры используют ликвидность розничных трейдеров:

1. **Манипуляция**: ММ снимают ликвидность (SSL/BSL)
2. **Ловушка**: Розничные трейдеры попадают в противоположную позицию
3. **Экспансия**: Истинное движение в направлении ММ

### Иерархия таймфреймов

- **D1/H4** (Стратегические): Глобальная структура и ключевые пулы ликвидности
- **H1/M30** (Промежуточные): Подтверждение манипуляции и уточнение зон
- **M15/M5** (Тактические): Слом структуры и определение точек входа
- **M1** (Снайперский): Ювелирное уточнение входа

### Ключевые элементы

#### Структура рынка
```python
class MarketStructure(Enum):
    BULLISH = "bullish"    # HH + HL
    BEARISH = "bearish"    # LL + LH
    RANGING = "ranging"    # Боковик
    UNDEFINED = "undefined"
```

#### Типы ликвидности
```python
class LiquidityType(Enum):
    BSL = "buy_side_liquidity"   # Над свинг-хаями
    SSL = "sell_side_liquidity"  # Под свинг-лоу
```

#### Зоны интереса
```python
class POIType(Enum):
    ORDER_BLOCK = "order_block"      # Последняя противоположная свеча
    IMBALANCE = "imbalance"          # Fair Value Gap
    SUPPORT = "support"              # Уровень поддержки
    RESISTANCE = "resistance"        # Уровень сопротивления
```

### Алгоритм работы

#### 1. Определение структуры рынка
```python
# Анализ трендовой структуры
if higher_highs and higher_lows:
    market_structure = "BULLISH"
elif lower_lows and lower_highs:
    market_structure = "BEARISH"
```

#### 2. Поиск ликвидности
- **BSL**: над свинг-максимумами (стопы лонгов)
- **SSL**: под свинг-минимумами (стопы шортов)

#### 3. Детекция манипуляции
- Пробой уровня ликвидности
- Быстрое возвращение цены
- Увеличение объема

#### 4. Вход в позицию
- Использование Order Blocks
- Подтверждение через Imbalances
- Confluence факторы

### Система конфлюенции

Вес факторов:
- **Структура рынка** (30%): соответствие тренду
- **Ликвидность** (25%): близость к BSL/SSL
- **Order Blocks** (20%): институциональные зоны
- **Imbalances** (15%): Fair Value Gaps
- **Fibonacci** (10%): ключевые уровни

### Человекоподобное мышление

Система реализует адаптивную логику:
```python
# Эмоциональные факторы
context.fear_factor = 0.1    # Страх после убытков
context.greed_factor = 0.05  # Жадность после прибыли

# Адаптация параметров
if recent_win_rate < 0.4:
    # Снижаем агрессивность после серии потерь
    confluence_threshold *= 1.2
    position_size *= 0.8
```

### Метрики производительности

#### Ключевые метрики
- **Общая доходность**: Общая производительность портфеля
- **Коэффициент Шарпа**: Доходность с поправкой на риск
- **Коэффициент Калмара**: Отношение доходности к макс. просадке
- **Винрейт**: Процент прибыльных сделок
- **Profit Factor**: Валовая прибыль / Валовый убыток
- **Максимальная просадка**: Наибольшее снижение от пика до дна

#### Метрики рисков
- **Value at Risk (VaR)**: Оценка потенциальных потерь
- **Conditional VaR**: Ожидаемые потери сверх VaR
- **Бета**: Корреляция с рынком
- **Альфа**: Избыточная доходность над рынком
- **Волатильность**: Стандартное отклонение доходности

## 🛡️ УПРАВЛЕНИЕ РИСКАМИ

### Принципы риск-менеджмента

1. **Максимальный риск на сделку**: 2% от депозита
2. **Максимум открытых позиций**: 3
3. **Минимальный R:R**: 2:1
4. **Стоп-лосс**: структурные уровни
5. **Take Profit**: следующий пул ликвидности

### Адаптивное управление

Система автоматически:
- Уменьшает размер позиций после серии убытков
- Увеличивает размер при высоком качестве сигналов
- Корректирует параметры на основе производительности

### Эмоциональные факторы

```python
# Страх после убытков
if recent_losses > 3:
    position_size *= 0.8
    confluence_threshold *= 1.2

# Жадность после прибыли
if recent_wins > 5:
    position_size *= 0.9  # предотвращение переторговли
```
