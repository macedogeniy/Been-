# Анализ стратегии "Охота за ликвидностью" и план разработки

## Декомпозиция стратегии

### 1. Иерархия таймфреймов и их функции:

**Стратегические таймфреймы (D1, H4):**
- Определение глобальной структуры рынка (MS)
- Поиск ключевых пулов ликвидности (BSL/SSL)
- Идентификация зон-ловушек (HTF SnR)

**Промежуточные таймфреймы (H1, M30):**
- Подтверждение манипуляции
- Уточнение зон интереса (POI)
- Наблюдение за подходом цены к POI

**Тактические таймфреймы (M15, M5):**
- Ключевой слом структуры (ChoCh)
- Определение точного POI для входа
- Принятие решения о входе

**Снайперский таймфрейм (M1):**
- Ювелирное уточнение точки входа
- Микро-слом структуры внутри POI

### 2. Ключевые концепции для реализации:

**Структура рынка (Market Structure):**
- Бычья: Higher Highs (HH) + Higher Lows (HL)
- Медвежья: Lower Lows (LL) + Lower Highs (LH)
- Слом структуры (ChoCh): пробой последнего значимого свинга

**Ликвидность:**
- BSL (Buy Side Liquidity): над свинг-максимумами
- SSL (Sell Side Liquidity): под свинг-минимумами
- Снятие ликвидности: пробой этих уровней

**Зоны интереса (POI):**
- Order Blocks (OB): последняя свеча противоположного цвета перед импульсом
- Imbalances (FVG): разрывы между свечами
- Support & Resistance: уровни разворота

**Манипуляция и экспансия:**
- Манипуляция: ложные пробои для снятия ликвидности
- Экспансия: истинное движение после манипуляции

## Архитектура системы

### Модульная структура:

1. **DataManager** - управление данными
2. **MarketStructureAnalyzer** - анализ структуры рынка
3. **LiquidityDetector** - поиск ликвидности
4. **POIIdentifier** - определение зон интереса
5. **SignalGenerator** - генерация сигналов
6. **RiskManager** - управление рисками
7. **Backtester** - бэк-тестинг
8. **Visualizer** - визуализация
9. **Logger** - логирование

### Технологический стек:

- **Python 3.9+** - основной язык
- **ccxt** - получение данных с бирж
- **pandas/numpy** - обработка данных
- **ta-lib/pandas_ta** - технические индикаторы
- **asyncio** - асинхронная обработка
- **plotly** - интерактивная визуализация
- **sqlite/postgresql** - хранение данных
- **pytest** - тестирование
- **logging** - логирование

## Особенности реализации

### Человекоподобное мышление:
- Использование нечеткой логики для принятия решений
- Адаптация к изменяющимся рыночным условиям
- Учет контекста предыдущих сделок

- Реалистичные условия исполнения
- Синхронизация между таймфреймами

### Производительность:
- Векторизованные вычисления
- Асинхронная обработка данных
- Кэширование промежуточных результатов
- Оптимизированные алгоритмы поиска паттернов
