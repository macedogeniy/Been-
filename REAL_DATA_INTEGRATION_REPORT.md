### 1. Новый модуль загрузки данных

- **Класс `HistoricalDataFetcher`** - основной загрузчик реальных данных

## 📊 Технические характеристики

### Источники данных
| Биржа | Таймфреймы | Символы | Лимиты |
|-------|------------|---------|--------|
| Binance | 1m-1d | BTC/USDT, ETH/USDT, etc. | 1200/min |
| Binance Futures | 1m-1d | Все основные | 1200/min |
| Coinbase | 1m-1d | BTC-USD, ETH-USD | 10/sec |

### Кэширование
- **Формат:** Pickle (pandas DataFrame)
- **TTL:** 24 часа
- **Размер:** ~1-5 MB на 30 дней часовых данных
- **Локация:** `data/cache/`

### Производительность
- **Загрузка 30 дней (H1):** 2-5 секунд
- **Кэш-попадание:** <100ms
- **Объем данных:** ~720 свечей за 30 дней (H1)

```python
import asyncio
from data.historical_data_fetcher import get_demo_data
from core.data_types import TimeFrame

async def main():
    # Загрузка реальных данных BTC/USDT за 30 дней
    data = await get_demo_data("BTC/USDT", TimeFrame.H1, 30)
    print(f"Загружено {len(data)} реальных свечей")
    
    # Анализ реальной структуры рынка
    from analysis.market_structure import MarketStructureAnalyzer
    analyzer = MarketStructureAnalyzer()
    
    structure = analyzer.analyze_structure(data)
    print(f"Структура рынка: {structure.value}")

asyncio.run(main())
```
