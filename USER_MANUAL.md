## 📋 Введение и обзор

Торговая система "Охота за ликвидностью" - это профессиональная система алгоритмической торговли, реализующая продвинутую стратегию поиска и использования ликвидности на рынке BTC/USDT.

### ✨ Ключевые особенности

- **🎯 Стратегия "Охота за ликвидностью"**: Поиск BSL/SSL пулов и их использование
- **📊 Многотаймфреймовый анализ**: От D1 до M1 с синхронизацией
- **🧠 Человекоподобное мышление**: Адаптивная логика с эмоциональными факторами
- **📈 Детекция структуры**: HH/HL, LL/LH паттерны
- **🎨 Интерактивная визуализация**: Plotly графики с полной разметкой
- **🧪 Профессиональный бэк-тестинг**: Комплексная система анализа производительности
- **🖥️ Веб-дашборд**: Streamlit интерфейс для мониторинга
- **🚨 Система алертов**: Email, Telegram, Webhook уведомления

### 🏗️ Архитектура

## 🔧 Конфигурация системы

### Основной файл конфигурации (.env)

Отредактируйте файл `.env` согласно вашим требованиям:

#### Настройки биржи
```env
# Выберите биржу (binance, bybit, okx)
EXCHANGE_NAME=binance
EXCHANGE_SANDBOX=true  # true для тестов

# API ключи (получите в личном кабинете биржи)
EXCHANGE_API_KEY=your_api_key
EXCHANGE_SECRET=your_secret
```

#### Торговые настройки
```env
TRADING_SYMBOL=BTC/USDT
TRADING_MAX_RISK_PER_TRADE=0.02  # 2% на сделку
TRADING_MAX_OPEN_POSITIONS=3
TRADING_MIN_RR_RATIO=2.0
TRADING_MIN_CONFLUENCE_SCORE=0.7
```

#### Настройки стратегии
```env
STRATEGY_LIQUIDITY_SENSITIVITY=0.8
STRATEGY_MIN_LIQUIDITY_AGE=5
STRATEGY_OB_VALIDITY_PERIOD=50
```

### Получение API ключей

#### Binance
1. Зайдите на https://www.binance.com
2. Профиль → API Management
3. Создайте новый API ключ
4. Включите "Enable Spot & Margin Trading" (для реальной торговли)

#### Bybit
1. Зайдите на https://www.bybit.com
2. API → API Management
3. Создайте системный API ключ

## 🧪 Бэк-тестирование

### Простой бэк-тест

```bash
python simple_backtest_demo.py
```

### Настройка параметров бэк-теста

В файле `.env`:
```env
BACKTEST_START_DATE=2023-01-01
BACKTEST_END_DATE=2024-01-01
BACKTEST_INITIAL_BALANCE=10000.0
BACKTEST_COMMISSION=0.001
BACKTEST_SLIPPAGE=0.0005
```

### Интерпретация результатов

Система создает файлы в папке `backtest_results/`:
- `*_report.txt` - текстовый отчет с метриками
- `*_metrics.json` - JSON с подробными метриками
- `*_trades.json` - история всех сделок
- `*_equity.csv` - изменения эквити

#### Ключевые метрики:
- **Total Return**: общая доходность
- **Sharpe Ratio**: соотношение доходности к риску
- **Max Drawdown**: максимальная просадка
- **Win Rate**: процент прибыльных сделок
- **Profit Factor**: отношение прибыли к убыткам

## 🎯 Стратегия "Охота за ликвидностью"

### Концепция

Стратегия основана на понимании того, как маркет-мейкеры манипулируют розничными трейдерами:

1. **Накопление ликвидности** - формирование BSL/SSL пулов
2. **Манипуляция** - ложный пробой для активации стопов
3. **Экспансия** - истинное движение в противоположную сторону

### Алгоритм работы

#### 1. Определение структуры рынка
```python
# Анализ трендовой структуры
if higher_highs and higher_lows:
    market_structure = "BULLISH"
elif lower_lows and lower_highs:
    market_structure = "BEARISH"
```

#### 2. Поиск ликвидности
- **BSL**: над свинг-максимумами (стопы лонгов)
- **SSL**: под свинг-минимумами (стопы шортов)

#### 3. Детекция манипуляции
- Пробой уровня ликвидности
- Быстрое возвращение цены
- Увеличение объема

#### 4. Вход в позицию
- Использование Order Blocks
- Подтверждение через Imbalances
- Confluence факторы

### Система конфлюенции

Вес факторов:
- **Структура рынка** (30%): соответствие тренду
- **Ликвидность** (25%): близость к BSL/SSL
- **Order Blocks** (20%): институциональные зоны
- **Imbalances** (15%): Fair Value Gaps
- **Fibonacci** (10%): ключевые уровни

## ⚖️ Управление рисками

### Принципы риск-менеджмента

1. **Максимальный риск на сделку**: 2% от депозита
2. **Максимум открытых позиций**: 3
3. **Минимальный R:R**: 2:1
4. **Стоп-лосс**: структурные уровни
5. **Take Profit**: следующий пул ликвидности

### Адаптивное управление

Система автоматически:
- Уменьшает размер позиций после серии убытков
- Увеличивает размер при высоком качестве сигналов
- Корректирует параметры на основе производительности

### Эмоциональные факторы

```python
# Страх после убытков
if recent_losses > 3:
    position_size *= 0.8
    confluence_threshold *= 1.2

# Жадность после прибыли
if recent_wins > 5:
    position_size *= 0.9  # предотвращение переторговли
```

## ❓ FAQ

### Q: Можно ли использовать для других криптовалют?
A: Да, измените параметр `TRADING_SYMBOL` в .env файле.

### Q: Поддерживается ли реальная торговля?
A: Да, установите `EXCHANGE_SANDBOX=false` и используйте реальные API ключи.

### Q: Как изменить таймфреймы для анализа?
A: Настройте параметры в конфигурации:
```env
TRADING_STRATEGIC_TIMEFRAMES=1d,4h
TRADING_TACTICAL_TIMEFRAMES=15m,5m
```

### Q: Как добавить уведомления в Slack?
A: Используйте webhook URL:
```env
ALERT_WEBHOOK_ENABLED=true
ALERT_WEBHOOK_URL=https://hooks.slack.com/services/...
```

### Q: Можно ли запустить несколько экземпляров?
A: Да, создайте отдельные .env файлы и папки для каждого экземпляра.

### Q: Как оптимизировать параметры стратегии?
A: Используйте модуль оптимизации в бэк-тестинге:
```env
BACKTEST_ENABLE_OPTIMIZATION=true
BACKTEST_OPTIMIZATION_METRIC=sharpe_ratio
```
