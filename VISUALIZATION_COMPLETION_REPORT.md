## 🎨 Ключевые особенности

### 1. Интерактивные графики
**ChartVisualizer** предоставляет:
- **Комплексные графики:** 3 субплота (цена + объем + RSI)
- **Полная разметка стратегии:**
  - Свинг-точки с индикацией силы
  - BSL/SSL зоны ликвидности
  - Order Blocks (бычьи/медвежьи)
  - Fair Value Gaps (imbalances)
  - Уровни поддержки/сопротивления
- **Торговые сигналы:** с контекстной информацией
- **Настраиваемое оформление:** темная/светлая тема
- **Экспорт:** HTML, PNG, JSON

### 2. Веб-дашборд
**TradingDashboard** включает:
- **Реальное время:** автообновление каждые 30 сек
- **Боковая панель:** настройки символа, таймфрейма, отображения
- **Ключевые метрики:** P&L, винрейт, просадка, активные сигналы
- **Основной график:** полная интеграция с ChartVisualizer
- **Таблица сделок:** с цветовой индикацией прибыли/убытков
- **Дополнительная аналитика:**
  - Распределение P&L
  - Временной анализ (по часам)
  - Статистика по типам сигналов

### 3. Система алертов
**AlertManager** поддерживает:
- **Многоканальность:** Email, Telegram, Webhook, файлы, консоль
- **Типы алертов:**
  - `SIGNAL` - новые торговые сигналы
  - `TRADE_OPENED/CLOSED` - операции с позициями
  - `PROFIT_TARGET/STOP_LOSS` - цели и стопы
  - `PERFORMANCE` - отчеты о производительности
  - `SYSTEM_ERROR` - системные ошибки
- **Приоритизация:** LOW, MEDIUM, HIGH, CRITICAL
- **Умная логика:** автоопределение приоритета по качеству сигнала
- **История и статистика:** полное логирование и аналитика
