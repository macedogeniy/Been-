# 🚀 Быстрый старт: Торговая система "Охота за ликвидностью"

## 📋 За 5 минут до запуска

### 1. Проверьте требования
- Python 3.8+ ✅
- 4GB+ RAM ✅
- Подключение к интернету ✅

### 2. Установка
```bash
# Клонируйте проект
git clone <repository_url>
cd liquidity-hunt-system

# Создайте виртуальное окружение
python -m venv venv
source venv/bin/activate  # Linux/Mac
# venv\Scripts\activate   # Windows

# Автоматическая настройка
python quickstart.py --setup
```

### 3. Первый запуск
```bash
# Интерактивное меню
python quickstart.py

# Или выберите режим:
python quickstart.py --mode demo      # Демонстрация
python quickstart.py --mode dashboard # Веб-интерфейс
python quickstart.py --mode backtest  # Бэк-тест
```

## 🆘 Помощь

### Если что-то не работает:
1. **Проверьте зависимости**: `python quickstart.py --install-deps`
2. **Изучите логи**: папка `logs/`
3. **Читайте мануал**: `USER_MANUAL.md`
4. **Запустите тесты**: `python quickstart.py --mode test`

### Частые проблемы:
- **Python не найден**: Установите Python 3.8+
- **Ошибки зависимостей**: `pip install -r requirements.txt`
- **Проблемы с API**: Проверьте ключи в `.env`
- **Медленная работа**: Уменьшите период анализа
