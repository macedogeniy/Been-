## 🔍 Основные ICT концепции, примененные в анализе

### Liquidity Concepts:
- **Buy Side Liquidity (BSL)** - зоны покупателей для таргетинга
- **Sell Side Liquidity (SSL)** - зоны продавцов для манипуляций
- **Liquidity Sweeps** - захват ликвидности перед реальным движением

### Market Structure:
- **Market Structure Shift (MSS)** - смена структуры рынка
- **Change of Character (CHoCH)** - изменение характера движения  
- **Break of Structure (BOS)** - пробой структуры

### Entry Techniques:
- **Order Blocks (OB)** - зоны институциональных ордеров
- **Fair Value Gap (FVG)** - неэффективность в доставке цены
- **Optimal Trade Entry (OTE)** - 61.8%-78.6% Fibonacci зоны

### Advanced Concepts:
- **Power of 3 (PO3)** - Accumulation → Manipulation → Distribution
- **Institutional Order Flow** - понимание поведения "умных денег"
- **Market Maker Model** - алгоритм движения цены
